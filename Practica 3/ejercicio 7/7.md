# Ejercicio 7 - Uso de módulos

`module-info.java` es el descriptor del módulo. Declara su nombre, qué otros
módulos necesita, qué paquetes expone y, si hiciera falta, los servicios que
consume o provee. Permite que el compilador y la JVM verifiquen dependencias y
encapsulen los paquetes que no se exportan.

En `loggingutils` se incluye:

```java
requires java.logging;
exports loggingutils;
```

`exports loggingutils` hace accesible la clase pública `loggingutils.Logger` a
otros módulos. Sí es necesario declarar `requires java.logging`: todo módulo
lee implícitamente `java.base`, pero no los demás módulos de la plataforma.
La clase `java.util.logging.Logger` pertenece al módulo `java.logging`.

El módulo `test` declara `requires loggingutils` para poder importar y usar el
Logger. Se mantuvo el Singleton implementado en la práctica 1 y se reemplazó la
impresión manual por los niveles `INFO`, `WARNING` y `SEVERE` de
`java.util.logging`.

## Compilar y ejecutar

Desde `Practica 3/ejercicio 7/project`:

```bash
javac -d out --module-source-path "./*/src" -m loggingutils,test
java --module-path out -m test/test.Main
```
