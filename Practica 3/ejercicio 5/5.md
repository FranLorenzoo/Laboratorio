# Ejercicio 5

La clase interna con nombre fue reemplazada por la expresión
`new Iterator<String>() { ... }` dentro de `iterator()`.

**a)** Conviene usar una clase anónima cuando se necesita una implementación
corta, local y de un solo uso, y darle un nombre no mejoraría la comprensión o
la reutilización. Para comportamientos grandes o repetidos es preferible una
clase con nombre. Si solo se implementa una interfaz funcional, una lambda
puede ser todavía más simple.

**b)** Una clase anónima no puede declarar un constructor porque no tiene
nombre. Sus valores pueden inicializarse:

- en la declaración de sus campos;
- mediante un bloque inicializador de instancia, como el usado en `Stack`;
- capturando variables locales finales o efectivamente finales del contexto;
- si extiende una clase, pasando argumentos al constructor de la superclase en
  la propia expresión `new Superclase(argumentos) { ... }`.

## Compilar y ejecutar

Desde `Practica 3/ejercicio 5`:

```bash
javac -d out Stack.java
java -cp out practica3.Stack
```
