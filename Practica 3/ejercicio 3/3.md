# Ejercicio 3

`StringConverterSet` extiende `AbstractSet<String>`. Esta clase base implementa
las operaciones generales de `Set` a partir de `iterator()` y `size()`; la
solución redefine además `add()` y `clear()` para que la colección sea
modificable.

La clase anidada `IteratorStringAdapter` envuelve el iterador del conjunto
interno. Delega `hasNext()` y `remove()`, y adapta `next()` mediante
`String.valueOf(...)`.

El constructor elimina colisiones de representación. Por ejemplo, `1` y
`"1"` no pueden coexistir porque el iterador devolvería dos Strings iguales y
se violaría el contrato de `Set<String>`.

## Compilar y ejecutar

Desde `Practica 3/ejercicio 3`:

```bash
javac -d out StringConverterSet.java TestStringConverterSet.java
java -cp out practica3.TestStringConverterSet
```
