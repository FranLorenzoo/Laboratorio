# Ejercicio 2

El radio se recibe en tiempo de ejecución y se pasa al constructor de la clase
anidada estática `InnerStatic.Circulo`. Al ser `static`, se crea con
`new InnerStatic.Circulo(radio)` y no requiere un objeto `InnerStatic`.

El `import static java.lang.Math.pow` permite escribir `pow(radio, 2)` sin
anteponer `Math.`.

## Inferencia de tipos con `var`

Tanto `a` como `l` son de tipo `double`:

- `pow(...)` retorna `double`, por lo que el resultado de `PI * pow(...)` es
  `double`.
- `PI` y `radio` son `double`; las promociones numéricas hacen que
  `2 * PI * radio` también sea `double`.

`var` solo puede utilizarse para variables locales con inicializador, variables
de iteración y recursos de `try`. El tipo se decide en compilación a partir del
inicializador; no convierte a Java en un lenguaje de tipado dinámico.

En este código también sería válido usarlo en `InnerTest` para `radio` si se lo
declarara e inicializara en una sola sentencia, para `entrada` y para
`circulo`. No puede usarse en `PI`, `radio` (el atributo), parámetros, tipos de
retorno ni en una variable local sin inicializador. Tampoco admite un
inicializador `null` aislado, porque no habría un tipo que inferir.
