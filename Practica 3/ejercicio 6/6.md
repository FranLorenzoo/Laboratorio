# Ejercicio 6

Los cuatro criterios se implementan como clases anónimas de
`Comparator<Estudiante>` y se pasan a `Arrays.sort()`.

Antes de cada ordenamiento se copia el arreglo original. Así cada criterio se
aplica sobre los mismos datos iniciales y el resultado anterior no se usa como
desempate accidental. Se emplea `Integer.compare` en lugar de restar enteros,
evitando posibles desbordamientos.

## Compilar y ejecutar

Desde `Practica 3/ejercicio 6`:

```bash
javac -d out Estudiante.java
java -cp out practica3.Estudiante
```
